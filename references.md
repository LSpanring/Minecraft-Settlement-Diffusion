## Note on the "Byrne et al. 2020 / TopoDiffusionNet" comment (row 10)

The `train_diffusion.py` code comment cites "Byrne et al. 2020 / TopoDiffusionNet" as if it were one source — it isn't. These are two separate papers from different years:
- The actual 2020 persistent-homology loss paper is **Clough et al. (2020)**, with Byrne as a co-author, not the lead author — cite it as Clough et al., not "Byrne et al."
- **TopoDiffusionNet** is unrelated later work (submitted 2024, ICLR 2025) that applies a topology objective specifically to diffusion models, which is closer in spirit to what this project's `connectivity_boost` mechanism is a simplified proxy for, but it postdates most of this project's implementation and almost certainly wasn't the literal source consulted when `compute_connectivity_weight` was written.

Cite whichever one you can actually verify you drew the idea from; don't cite both as if the code comment's shorthand were a real joint reference.

## Note on citation years

Several of these have a preprint year and a later venue-publication year that differ by one (e.g., Chen et al.'s Analog Bits is arXiv 2022 / ICLR 2023; Perez et al.'s FiLM is arXiv 2017 / AAAI 2018). The code comments are inconsistent about which year they use — pick one convention (I'd recommend the venue/publication year, which is what natbib/BibTeX entries from the venue will give you) and apply it consistently across the thesis.
